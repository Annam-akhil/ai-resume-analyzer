# AI Resume Analyzer 

## Demo

Live Demo: Coming Soon (Streamlit Cloud Deployment)

An AI-powered application that analyzes resumes and provides ATS optimization suggestions using NLP and machine learning.

## Features

- ATS Resume Score
- Resume vs Job Description Matching
- Skill Gap Detection
- AI Resume Improvement Suggestions
- Interview Question Generator

## Tech Stack

Python  
Streamlit  
Sentence Transformers  
Transformers  
Scikit-learn  

## Installation

git clone https://github.com/Annam-akhil/ai-resume-analyzer

cd ai-resume-analyzer

pip install -r requirements.txt

streamlit run app.py
